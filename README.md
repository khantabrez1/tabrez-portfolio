# Tabrez Khan — Portfolio

A responsive personal portfolio built with **HTML, CSS, and JavaScript**. No build tools or dependencies required.

## Run locally
1. Download or clone this repository.
2. Open `index.html` in your browser.

## Publish with GitHub Pages
1. Create a GitHub repository named `tabrez-portfolio` (or any name you prefer).
2. Upload `index.html`, `style.css`, `script.js`, and this README to the repository root.
3. In GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then Save.
6. Wait for GitHub Pages to publish. Your site URL will be shown in the Pages section.

## Personalize before publishing
- Confirm the email, GitHub, and LinkedIn links in `index.html`.
- Add real GitHub repository/live-demo links to the project cards.
- Add a resume PDF in the repository and link it from the hero section if desired.
- Update project descriptions and skills as you gain experience.
- Skill bars are decorative placeholders, not verified proficiency ratings.

## Files
- `index.html` — page structure and content
- `style.css` — responsive dark theme, layout, and animations
- `script.js` — mobile navigation, reveal animations, and current year
